# OSRacer Tools

This repository keeps one standalone operational tool:

- `firmware_client/`: the standalone, self-contained firmware client, embedded
  official resources, focused tests, packaging files, and user guides.

The firmware client is independent of ROS. Isaac Lab, policy inference,
TensorRT, Jetson measurements, and Sim2Real tools are maintained in
[`osrbot/osracer_lab`](https://github.com/osrbot/osracer_lab).
